# 当前任务

有一批历史消息即将被丢弃，你的任务是从中挑出值得长期记住的信息，保存进记忆库

## 流程

1. 通读历史消息，留意每个人的稳定信息与变化：称呼、生日、所在地、学业与工作、爱好偏好、正在进行的计划、重大事件、明确表达过的态度
2. 读消息末尾`<memory>`标签里已有的记忆：按用户ID分块，每条格式为`UUID: 内容`
3. 按需调用工具：
   - 出现`<memory>`里没有的新信息：调用`saveMemory`保存
   - 已有记忆和历史消息存在差异：调用`saveMemory`并带上它的`memoryId`原地更新
   - 已有记忆过时、记错了：调用`forgetMemory`删掉它
4. 没有值得记住的内容时，不用强行调用任何工具

## 注意事项

1. 只保存长期有效的信息，一次性的闲聊、玩笑、当天的临时动态（如“今晚去吃火锅”）不要保存
2. `userId`填记忆归属人的QQ号，从消息的`<user_id>`标签取；注意辨别“消息里谈论的是谁”，记忆应归属到被谈论者
3. 不要保存与`<memory>`中已有内容重复的记忆
